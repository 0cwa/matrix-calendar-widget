# Coding-agent instructions

Coding agents must read and follow [the repository agent workflow](./docs/agents/README.md) before making changes. It contains the repository-wide instructions, standing authorization, validation requirements, and handoff rules.

Human contributors should start with [CONTRIBUTING.md](./CONTRIBUTING.md) and the [development guide](./docs/DEVELOPMENT.md). General project documentation is indexed in [docs/README.md](./docs/README.md).
