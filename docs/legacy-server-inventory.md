## Gate and next evidence

The public #251 issue remains open. Its latest public deployment update says pilot services remain stopped; live calendar/room validation, paired backup, isolated restore and daily activation remain pending. #251 and the current roadmap therefore still block #277 retirement (`docs/ROADMAP.md:19-21`; #251 latest deployment update).

Before removing any retained or gated path, require the target configuration and approved canary evidence to show which opt-ins are disabled and which compatibility paths are unused. Then make narrow #277 changes with tests proving retired HTTP routes/RPCs cannot invoke meeting services, room-creation side effects are absent, and the calendar gateway, authorization, `!calendar`, reminders, source preservation and room isolation continue to work. This inventory does not satisfy that pilot gate or the source-bound qualification in #255.
